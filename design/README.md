# Design System Notes — سنگا

## Direction

Premium, trustworthy, operational SaaS for stone sellers.  
Persian-first, RTL, mobile-first, image-focused.  
Avoid generic “AI dashboard” aesthetics (no purple glow kits, no newspaper layouts, no cream/terracotta cliché).

## Visual Direction (v1)

- Deep stone slate + warm limestone accent  
- CSS variables for semantic colors  
- Clean surfaces with subtle depth; minimal gradients  
- Expressive Persian-capable font stack (e.g. Vazirmatn)  

## Tokens (initial)

- Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48  
- Radius: sm 6 / md 10 / lg 16  
- Shadows: soft elevation only  
- Type: display / title / body / caption / overline  

## Components to ship in Phase 1 shell

Button, Input, Badge, Toast region, Modal shell, EmptyState, Skeleton, AppShell, BottomNav, Stepper, FilterChip, StatusDot.

Cards only for interactive containers.
