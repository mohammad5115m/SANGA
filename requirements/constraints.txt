# requirements/*.txt say what SANGA depends on and which versions are acceptable.
# This file says which versions were actually reviewed and tested, so two builds
# of the same commit install the same bytes. Without it, a rebuild after an
# upstream release ships something nobody looked at, and "it worked yesterday"
# stops being a useful thing to say.
#
# Regenerate deliberately, as its own reviewed change:
#
#     pip install -r requirements/production.txt --upgrade
#     pip freeze > requirements/constraints.txt   # then prune dev-only entries
#
# Used with -c, not -r: the requirements files stay the source of truth for what
# is a dependency, and this only constrains the resolution.
